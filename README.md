# Ecommerce Full Stack Web Application

A modern full-stack ecommerce web application built using React, Node.js, Express, MongoDB Atlas, and Nodemailer.
This project includes user authentication, navigation system, cart functionality, responsive UI, email services, and global state management using React Context API.

##  Tech Stack
Frontend
React.js
React Router DOM
React Context API
CSS3
Responsive Design

## Backend
Node.js
Express.js
MongoDB Atlas
Mongoose
JWT Authentication
bcryptjs
Nodemailer

## Features
User Registration & Login
JWT Authentication
Protected Routes
Responsive Navigation Bar
Product Listing Page
Single Product Details Page
Add to Cart Functionality
Cart View Page
React Context API State Management
Email Sending using Nodemailer
MongoDB Atlas Database
